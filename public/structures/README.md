# Structure Files Directory

This directory stores ColabFold / AlphaFold2 predicted structure files for frontend visualization.

## File Naming Convention

- `candidate_1.pdb`
- `candidate_2.pdb`
- `candidate_3.pdb`

## Metadata

Structure metadata (sequence, pLDDT, secondary structure composition) is defined in:

- `src/data/structureMetadata.ts` (current mock data)
- Or `structure-metadata.json` (future backend-generated)

## Secondary Structure Annotation

Secondary structure proportions (helix / sheet / coil) should be generated by DSSP / STRIDE or equivalent tools from the PDB files.

## Future Complete Workflow

```
Candidate peptide sequences
    ↓
ColabFold / AlphaFold2 prediction
    ↓
PDB output + pLDDT extraction
    ↓
DSSP / STRIDE secondary structure annotation
    ↓
Generate structure-metadata.json
    ↓
Frontend Mol* visualization
```

## Important Notes

- Short peptides may be flexible and environment-dependent.
- Predicted structures are for computational screening reference only.
- Experimental validation (CD spectroscopy, NMR, X-ray crystallography) is required for definitive structural confirmation.
- Replace placeholder PDB files with real ColabFold outputs before production use.
