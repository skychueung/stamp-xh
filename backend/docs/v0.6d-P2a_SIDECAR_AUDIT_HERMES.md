## 4. 不实指控的纠正

初审 (00:25) 中 5001 返回 connection refused 的根因：

- **非 Sidecar 未启动**。5001 设计为仅监听 `127.0.0.1`（安全最佳实践），WSL 环境通过 HTTP_PROXY 路由时被代理拦截返回 502，`--noproxy` 直连时因跨网络不可达。
