## 3. API 函数草案 — `src/lib/stampBackendApi.ts`

### 3.1 现有函数无需修改

当前 `buildStampCandidate()` (lines 53–66) 已完全正确:

```typescript
export async function buildStampCandidate(payload: {
  candidate_id: string;
  amp_name?: string | null;
}): Promise<{ candidate: StampBackendCandidate | null; error?: string }> {
  const body = JSON.stringify({
    candidate_id: payload.candidate_id,
    amp_name: payload.amp_name ?? null,
  });
  const { data, error } = await apiFetch<StampBackendCandidate>('/api/v1/stamp/build', {
    method: 'POST',
    body,
  });
  return { candidate: data, error };
}
```

**接口契约**:
| 字段 | 值 | 说明 |
|:------|:------|:------|
| Method | `POST` | |
| Path | `/api/v1/stamp/build` | |
| Content-Type | `application/json` | |
| body.candidate_id | `"OPRF_0001"` | 必填，对应表格行的 `candidate_id` |
| body.amp_name | `null` | 默认 P4；未来可扩展 |
| Response | `{code:200, message:"...", data:StampCandidate}` | ApiResponse 包装 |
| Error (网络) | `BACKEND_UNAVAILABLE_MSG` | "STAMP backend is not available..." |
| Error (HTTP 4xx/5xx) | `data:null, error:"HTTP NNN"` | 含 message 体 |

```typescript
async function handleSendToStamp(candidateId: string) {
  // 防止并发构建
  if (stampBuild.loading) return;

  setStampBuild({
    loading: true,
    activeCandidateId: candidateId,
    result: null,
    error: undefined,
  });

  const { candidate, error } = await buildStampCandidate({ candidate_id: candidateId });
  setStampBuild({
    loading: false,
    activeCandidateId: candidateId,
    result: candidate,
    error,
  });
}
```
