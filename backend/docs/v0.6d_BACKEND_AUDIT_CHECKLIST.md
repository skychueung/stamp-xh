## 异常/偏离说明

### 偏离 1: `/api/v1/stamp/demo-one` 命名约定

当前端点 `GET /api/v1/stamp/demo-one` 在代码中存在（`stamp.py:198-233`），但请注意它与 `POST /api/v1/stamp/build` 的关系:
- `demo-one`: **自动**选择最低 PPL 的 PepMLM 候选 + P4 (GET, 无需参数)
- `build`: **手动**指定 candidate_id + 可选 amp_name (POST, 接受 JSON body)

两个端点本质上调用同一个 `build_stamp()` 服务函数，区别在于选择逻辑。

### 偏离 2: BiophysicalProperties 部分字段为 None

`pI`、`GRAVY`、`hydrophobicity_fraction` 在 `BiophysicalProperties` 中默认为 `None`（见 `schemas.py:248-258`）。计算函数已存在于 `biocalc.py` 但 `stamp_builder.py` 未调用。这是**有意为之的设计决策**（注释标注 "not yet computed / deferred"），不影响科学诚信。

### 偏离 3: app_version 显示

`config.py:54` 中 `app_version: str = "0.6.0"` — 这是 API 版本号，不等同于项目版本号 `v0.6d`。`/health` 返回的 `version` 字段由 `health.py` 硬编码为 `v0.6d`。
