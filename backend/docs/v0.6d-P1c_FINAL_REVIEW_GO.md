## 5. 下一阶段真实 BepiPred3/ESM 接入路线

### 5.1 方案 A（Sidecar）— 推荐立即执行

**核心思路**: 旧 Flask 后端独立 Docker 运行在 5001 端口，Nginx 将 `/api/predict` 代理到 Flask。

```
当前架构:
  Browser → Nginx:8088 → FastAPI:8000 (/api/health, /api/predict demo-compatible)
                                    (/api/v1/stamp/*)

方案 A 架构:
  Browser → Nginx:8088 → /api/predict → Flask:5001 (真实 BepiPred3 + ESM + 五层筛选)
                       → /api/health  → Flask:5001
                       → /api/v1/*    → FastAPI:8000 (STAMP 不变)
```

**执行步骤（6 步，15-20 分钟）**:

```
步骤 1: 上传旧 Docker 镜像到服务器
  scp /mnt/d/Desktop/靶向肽/内网/peptide-app-fixed.tar \
      xh@192.168.31.218:/home/xh/kxc/靶向肽/内网/

步骤 2: 加载镜像
  ssh xh@192.168.31.218 "sudo docker load -i /home/xh/kxc/靶向肽/内网/peptide-app-fixed.tar"

步骤 3: 启动 Flask Sidecar
  ssh xh@192.168.31.218 "sudo docker run -d --name peptide-filter-backend \
    --network host \
    -v /home/xh/kxc/靶向肽/内网/migrate_pkg/peptide-app:/opt/peptide-app/backend \
    --entrypoint python3 \
    peptide-app:latest \
    /opt/peptide-app/backend/api_server.py"

步骤 4: 修复 BepiPred3 str/Path bug
  ssh xh@192.168.31.218 "sed -i 's/infile = Path(infile)/infile = Path(str(infile))/' \
    /home/xh/kxc/靶向肽/内网/migrate_pkg/peptide-app/bp3/bepipred3.py"

步骤 5: 配置 Nginx 代理
  在 stamp.conf 中添加:
    location /api/predict {
        proxy_pass http://127.0.0.1:5001;
        proxy_read_timeout 600s;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    location /api/health {
        proxy_pass http://127.0.0.1:5001;
        proxy_set_header Host $host;
    }
  nginx -s reload

步骤 6: 验证真实预测
  curl -X POST http://192.168.31.218:8088/api/predict \
    -H "Content-Type: application/json" \
    -d '{"name":"OPRF","sequence":"MNAFKVNRW...","min_len":5,"max_len":15,...}'
  # 预期: 返回实时计算的 10 条 ranked peptides + BepiPred3 表位得分
```
