### R4: stampBackendApi.ts 是否区分本地开发和生产同源请求

**判定**: 🟡 CONDITIONAL PASS — 生产机制有效，源码未清理

**源码现状** (src/lib/stampBackendApi.ts:3-4):

```typescript
const BASE_URL =
  (import.meta.env.VITE_STAMP_BACKEND_URL as string | undefined) ?? 'http://127.0.0.1:8000';
```

| 场景 | VITE_STAMP_BACKEND_URL | BASE_URL 结果 | 行为 |
|------|----------------------|--------------|------|
| 本地开发 (`npm run dev`) | 未设置 → undefined | `http://127.0.0.1:8000` | 直连本地后端 ✓ |
| 生产构建 (`npm run build`) | `.env.production` 设为空 `""` | `""` (空字符串) | 相对路径 `/api/v1/...` ✓ |
| 生产构建（.env.production 缺失） | undefined | `http://127.0.0.1:8000` ❌ | 回归 NO-GO |

**风险来源**: 构建依赖 `.env.production` 文件存在。经检查：

- 根目录 `.env.production`**: 不存在** (search_files 0 results)
- ZIP 内 `.env.production`**: 存在** (zipfile listing 确认)
- dist 构建产物**: 已使用空 BASE_URL** (相对路径已验证)

> 推断: 构建前临时创建了 `.env.production`，构建后未保留在源码根目录。

**建议**: 将 `.env.production` 提交到 Git 仓库，避免未来重新构建时回退到 127.0.0.1。

**风险等级**: LOW（当前 dist 正确，但缺少可重复性保障）

### R10: 是否仍不显示 fake ipTM / pDockQ / ΔG / MIC / MBC

**判定**: ✅ PASS — zero-fake 承诺严格执行

#### 构建产物分析

| 伪造指标 | dist/assets/index-gJI2544z.js | dist/assets/PeptideGenerationPage-CH4ddnsQ.js | 判定 |
|----------|------------------------------|---------------------------------------------|------|
| ipTM | 8 (翻译键+免责声明) | 0 | ✅ NOT RENDERED |
| pDockQ | 8 (翻译键+免责声明) | 0 | ✅ NOT RENDERED |
| ΔG (interface_dG) | 1 (免责声明文本中) | 0 | ✅ NOT RENDERED |
| MIC (单词边界 `\bMIC\b`) | **0** | 0 | ✅ NOT RENDERED |
| MBC (单词边界 `\bMBC\b`) | **0** | 0 | ✅ NOT RENDERED |
| dG (raw) | 1701 (minified 代码 false positive) | 1 (minified false positive) | ✅ NOT RENDERED |

#### 关键证据

**免责声明文本** (main bundle):

```
"由计算模型生成。无实验结合验证。无结构验证（ipTM、pDockQ、ΔG）。"
```

- ipTM/pDockQ/ΔG 在**免责声明**中作为"未验证项"被提及
- 这是透明度声明，明确告诉用户这些指标 **没有被实验验证**
- 与 zero-fake 承诺一致：不渲染伪造数据，且主动告知用户哪些指标不可用

**翻译键** (main bundle):

```javascript
ipTM: "ipTM（界面预测 TM 分数）"
pDockQ: "pDockQ（对接质量）"
```

- 标签定义存在于 i18n 系统中，但当前 P1a 版本**不渲染包含这些字段的 UI 组件**
- `validation_status` 在 chunk 中有 2 个引用 → 仅用于显示验证状态标签
- `NOT_EXPERIMENTALLY_VALIDATED` 在 chunk 中 **0 matches** → 数据从 API 获取，非硬编码渲染

#### 结论

界面中**不显示** ipTM、pDockQ、ΔG、MIC、MBC 的实际数值。免责声明明确标注这些指标未经实验验证，符合科研诚信要求。
