## 2. localStorage 配置

```typescript

// 读取
const lang = localStorage.getItem('stamp-language-preference'); // 'zh' | 'en' | null

// 写入
localStorage.setItem('stamp-language-preference', 'en');
```

## 4. 在组件中使用 `useLanguage()`

### 基础用法

```typescript
import { useLanguage } from '@/i18n/LanguageContext';

function MyComponent() {
  const { language, setLanguage, toggleLanguage, t, isZh, isEn } = useLanguage();
  
  return (
    <div>
      <h1>{t.pageTitle.structureValidation}</h1>
      <p>当前语言：{isZh ? '中文' : 'English'}</p>
      <button onClick={toggleLanguage}>切换</button>
    </div>
  );
}
```

### 切换语言

```typescript
// 直接设置
setLanguage('en');

// 切换
toggleLanguage(); // zh → en, en → zh
```

## 5. 如何新增翻译词条

### 步骤 1：在 translations.ts 中添加

```typescript
// src/i18n/translations.ts
export const translations = {
  zh: {
    myNewSection: {
      title: '新标题',
      description: '新描述',
    },
  },
  en: {
    myNewSection: {
      title: 'New Title',
      description: 'New Description',
    },
  },
} as const;
```

### 步骤 2：在组件中使用

```typescript
const { t } = useLanguage();
<h2>{t.myNewSection.title}</h2>
```

### 类型安全

由于 `as const` 断言，TypeScript 会自动推断所有 key。如果访问不存在的 key，会编译报错。

统一类型通过 `DeepStringify<T>` 处理：所有叶子字符串字面量被展开为 `string`，解决 `zh | en` 联合类型不兼容问题。


## 9. 常见问题

**Q: 切换语言后页面闪烁？**
A: 正常，React 会重新渲染。如性能敏感，可用 `React.memo` 包裹纯展示组件。

**Q: 旧页面 `/filter` 也想接入？**
A: 旧页面内容不接入 i18n 是设计决策（保持最小改动）。如需接入，需将页面内的硬编码文案替换为 `t.xxx`。

**Q: 科学术语如何统一？**
A: 建议维护 `docs/SCIENTIFIC_TERMS_GLOSSARY.md`，例如：

| 英文 | 中文 | 使用场景 |
|:---|:---|:---|
| Epitope Contact Ratio | 表位接触比例 | 界面显示 |
| ipTM | ipTM | 保留英文缩写 |
| pDockQ | pDockQ | 保留英文缩写 |
