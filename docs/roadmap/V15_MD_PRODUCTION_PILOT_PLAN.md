## 1. v1.5 Objective

Enable **real molecular dynamics (MD) production simulations** as a first-class citizen in the STAMP Batch Computation pipeline. The v1.5 pilot targets a **minimal 1 ns MD closed loop**:

1. Accept a candidate peptide + target protein complex (PDB)
2. Prepare simulation system (topology, solvation, minimization)
3. Run **real** 1 ns production MD
4. Parse real trajectory to extract RMSD / RMSF
5. Feed results into the Batch Computation framework
6. **No fabricated metrics at any stage**

## 3. 1 ns MD Pilot Minimum Closed Loop

### 3.1 Input Requirements

| Input | Format | Validation |
|-------|--------|------------|
| Peptide structure | PDB / FASTA | Sequence length ≥ 5 |
| Target protein | PDB | Must contain valid ATOM records |
| Complex | PDB (docked) | Or auto-dock via ColabFold / HADDOCK |
| Force field | Amber99SB-ILDN / CHARMM36m | Auto-selected if not specified |
| Water model | TIP3P / TIP4P-Ew | Auto-selected |
| Box type | Cubic / Dodecahedron | Auto-selected |
| Ion concentration | 0.15 M NaCl | Default |
| Simulation length | 1 ns (pilot) | Configurable in future |
| Temperature | 300 K | Configurable |
| Pressure | 1 bar | Configurable |
| Timestep | 2 fs | Configurable |
| Trajectory output | Every 10 ps (100 frames for 1 ns) | Configurable |

### 3.2 Output Requirements

| Output | File | Validation |
|--------|------|------------|
| Trajectory | `trajectory.xtc` / `trajectory.dcd` | File size > 0, frame count matches |
| Log | `md.log` | Contains "Finished mdrun" or equivalent |
| Energy | `energy.edr` | Parsable by GROMACS energy tool |
| RMSD | `rmsd.xvg` | Computed from real trajectory |
| RMSF | `rmsf.xvg` | Computed from real trajectory |
| Topology | `topol.top` + `*.itp` | Generated by real `pdb2gmx` |
| Coordinates | `confout.gro` | Final frame exists |

### 3.3 Status Machine

```
PENDING ──→ RUNNING ──→ SUCCEEDED
    │           │
    ↓           ↓
BLOCKED     FAILED
```

| Status | Condition |
|--------|-----------|
| **BLOCKED** | `gmx` not found, or `nvidia-smi` fails, or input PDB missing |
| **FAILED** | `gmx mdrun` exits non-zero, or topology generation fails, or input validation fails |
| **RUNNING** | `gmx mdrun` is actively executing |
| **SUCCEEDED** | `md.log` contains completion marker, `trajectory.xtc` exists with expected frames, RMSD/RMSF computed from real trajectory |

## 4. MD Engine Options

### 4.1 Option A: GROMACS (Recommended for v1.5)

**Pros:**
- Free, open-source, widely used
- Excellent GPU acceleration (CUDA)
- Strong community, extensive documentation
- Command-line friendly, easy to script

**Cons:**
- Not installed on server (P1 task)
- Requires compilation or package install

**Installation:**
```bash
sudo apt update
sudo apt install -y gromacs gromacs-openmpi
# Or compile from source with CUDA support
```

### 4.2 Option B: Amber (pmemd.cuda)

**Pros:**
- Industry standard for biomolecular MD
- `pmemd.cuda` extremely fast on GPU
- Excellent force fields

**Cons:**
- License required (academic free, but registration needed)
- Not installed
- Longer installation process

### 4.3 Option C: OpenMM

**Pros:**
- Python-native, easy integration
- Excellent GPU performance
- Free, no license

**Cons:**
- Python module not installed
- Less command-line oriented than GROMACS

**Installation:**
```bash
pip install openmm
```

### 4.4 Recommendation

**Primary:** GROMACS (Option A) — install via `apt` or conda  
**Secondary:** OpenMM (Option C) — install via `pip` for Python-native integration  
**Tertiary:** Amber (Option B) — deferred to v1.6+ due to license complexity

## 5. RMSD / RMSF Parsing Boundaries

**Rule: No fabricated metrics.**

| Metric | Source | Validation |
|--------|--------|------------|
| RMSD | `gmx rms` on real `trajectory.xtc` | Output file exists, values within physical range (0–10+ Å) |
| RMSF | `gmx rmsf` on real `trajectory.xtc` | Output file exists, values within physical range (0–10+ Å) |
| Rg | `gmx gyrate` on real trajectory | Output file exists |
| Energy | `gmx energy` on real `energy.edr` | Output file exists |

**Prohibited:**
- Hardcoded RMSD = 1.5 Å
- Hardcoded RMSF = 2.3 Å
- Synthetic trajectory files
- Empty `.xvg` files with fake headers

---

## 6. MM-GBSA Pilot Boundary

**Rule: MM-GBSA only after real MD trajectory exists.**

| Step | Condition |
|------|-----------|
| Input | `trajectory.xtc` + `topology.top` from real MD |
| Tool | `gmx_MMPBSA` (if GROMACS) or `mm_pbsa.pl` (if Amber) |
| Output | `FINAL_RESULTS_MMPBSA.dat` or equivalent |
| Status | BLOCKED if trajectory missing; FAILED if tool missing; SUCCEEDED only if real output file verified |

**Prohibited:**
- ΔG = -15.2 kcal/mol without real calculation
- Empty result files with fake values

## 7. Batch Computation Integration

The v1.5 MD pilot extends the existing Batch Computation framework:

```python
# New job_type values
VALID_JOB_TYPES = {"COLABFOLD", "FOLDX", "MMGBSA", "MIXED", "MD_PRODUCTION"}

# MD-specific input_json
{
    "sequence": "MKKTAIAATAVLATA",
    "target_pdb": "path/to/target.pdb",
    "complex_pdb": "path/to/complex.pdb",  # optional
    "force_field": "amber99sb-ildn",
    "water_model": "tip3p",
    "simulation_ns": 1,
    "temperature_k": 300,
    "ion_concentration_m": 0.15
}

# MD-specific output_json
{
    "trajectory_path": "data/batch_jobs/{batch_id}/md/trajectory.xtc",
    "rmsd_path": "data/batch_jobs/{batch_id}/md/rmsd.xvg",
    "rmsf_path": "data/batch_jobs/{batch_id}/md/rmsf.xvg",
    "energy_path": "data/batch_jobs/{batch_id}/md/energy.xvg",
    "frames": 100,
    "simulation_time_ns": 1.0
}
```

**Directory scaffold extension:**
```
data/batch_jobs/{batch_id}/
├── inputs/
├── colabfold/
├── foldx/
├── mmgbsa/
├── md/                    # NEW in v1.5
│   ├── topology/
│   ├── minimization/
│   ├── equilibration/
│   ├── production/
│   ├── analysis/
│   └── trajectory.xtc
├── logs/

└── artifacts/
```

## 8. Failure States

| State | Cause | User Action |
|-------|-------|-------------|
| **BLOCKED** | `gmx` not installed | Admin installs GROMACS |
| **BLOCKED** | No GPU available | Check `nvidia-smi`, restart driver |
| **BLOCKED** | Input PDB missing | Upload structure file |
| **FAILED** | `pdb2gmx` fails on input | Check PDB validity, fix missing atoms |
| **FAILED** | `gmx mdrun` crashes | Check log, fix parameters |
| **FAILED** | Trajectory file empty | Check disk space, check simulation parameters |
| **SUCCEEDED** | Real trajectory verified | Review RMSD/RMSF plots |

## 9. Scientific Boundaries (v1.5)

- ❌ **No fake RMSD** — must come from `gmx rms` on real trajectory
- ❌ **No fake RMSF** — must come from `gmx rmsf` on real trajectory
- ❌ **No fake ΔG** — must come from real MM-GBSA calculation
- ❌ **No fake trajectory** — `trajectory.xtc` must contain real frames
- ❌ **No fake energy** — must come from `energy.edr`
- ✅ **BLOCKED** when tools missing
- ✅ **FAILED** when input invalid or simulation crashes
- ✅ **SUCCEEDED** only after real output file verification
