## Root Cause: Why Round 1 Found Only 50

**Round 1 script error**: The `scanGroupDir()` function skipped directories named `原始文件` and `图片`, assuming they were documentation folders. In reality, `原始文件` contained 53 AMP structure directories (numbers 61-100 and fold_50-94).

**Impact**:
- Round 1: 50 AMPs scanned, 50 CIFs copied
- Round 2 (fix2): **102 AMPs scanned, 102 CIFs copied**

## 50 vs 100 vs 102 Problem - Root Cause Analysis

### Q1: ZIP contains 50 or 100 AMPs?
**Answer**: The ZIP contains **102** AMP directories, not 100. The naming "1-100" is approximate.

### Q2: Unzipped directory contains 50 or 100?
**Answer**: **102** directories in the unzipped source.

### Q3: Did the script only scan 50?
**Answer**: Round 1 script skipped `原始文件` directory, scanning only 50. Fix2 scans all 102.

### Q4: Why 515 CIF → 50 AMPs in Round 1?
**Answer**: 50 AMPs × 5 models = 250 CIFs (Round 1 visible). Skipped 52 AMPs × 5 = 260 CIFs. Total ~510 CIFs for 102 AMPs.

### Q5: Duplicates, hidden dirs, nested dirs?
**Answer**:
- One duplicate: `fold_50` appears in both AMP 30-50 and 原始文件
- No hidden directories found
- One nested ZIP found: `fold_50 (1).zip` inside 原始文件

### Q6: Final public/ should have 50 or 102?
**Answer**: **102** best models copied to `public/structures/real_amp_monomers/`.
