## 4. 已知限制（非阻塞）

1. **PDF 报告暂缺 per-item 明细表**  
   当前 PDF 为批次级摘要，单候选分子的 RMSD/RMSF/Rg/FlexPepDock/MM-GBSA 明细需在前端详情页或 Markdown/JSON 报告中查看。

2. **MD / FlexPepDock 报告目前主要显示文件存在性**  
   数值已可解析，但前端报告页面尚未完全内联展示所有时间序列图表（仅展示关键统计量）。

3. **磁盘使用率 90.5%**  
   1.8 TB 磁盘剩余 ~175 GB。MD trajectory 文件（20 MB/条）在批量生产场景下需定期归档或扩容。

4. **MM-GBSA gmx_MMPBSA 待安装**  
   Probe 显示 AVAILABLE（基础环境就绪），但 `gmx_MMPBSA` CLI 未找到。不影响已验证的真实 `.dat` 结果解析能力。

5. **前端 chunk 体积警告**  
   `index.js` ~5.3 MB（gzip 1.5 MB），需后续代码分割优化。不影响功能。
