## 1. 版本名称

STAMP v0.10 Integrated BepiPred3-to-PepMLM Workflow

---

## 2. 核心能力

本版本实现了从**真实表位预测**到**真实靶向肽生成**的端到端计算闭环：

| 能力 | 说明 |
|------|------|
| **BepiPred3 表位预测** | 通过 HTTP sidecar 调用真实 BepiPred3 模型，预测目标蛋白的候选表位 |
| **Job System** | 完整的异步 Job 生命周期：create → start/run → cancel → retry → persist |
| **BepiPred3 结果落库** | 预测结果自动写入 `epitope_scans` + `epitope_candidates` |
| **PepMLM-650M REAL_MODEL 生成** | 通过 HTTP sidecar 调用真实 PepMLM-650M 模型，基于表位生成靶向肽 |
| **PepMLM 结果落库** | 生成结果自动写入 `stamp_generation_runs` + `stamp_candidates` |
| **前端展示** | `EpitopeScreeningPage`、`ProjectResultsPage`、`FinalRankingPage` 支持真实数据展示 |
| **一体化 Workflow 脚本** | `backend/scripts/run_bepipred3_to_pepmlm_workflow.py` 一键执行全链路 |

---

## 3. 当前真实模型

| 模型 | 类型 | 运行方式 | 设备 |
|------|------|----------|------|
| BepiPred3 | 真实模型 | HTTP Sidecar (`:5001`) | CPU |
| PepMLM-650M | 真实模型 (REAL_MODEL) | HTTP Sidecar (`:5011`) | CPU |

> **注意**：当前两个 sidecar 均运行在 **CPU 模式**。BepiPred3 对长序列（>500 aa）推理可能较慢；PepMLM 的 GPU 加速支持将在后续版本评估。

## 6. 科研边界

所有本版本产生的候选数据均明确标注：

- `validation_status`: `NOT_EXPERIMENTALLY_VALIDATED`
- `prediction_status`: `COMPUTATIONAL_PREDICTION_ONLY`（BepiPred3）

## 7. 已知限制

| 限制 | 说明 | 计划解决版本 |
|------|------|--------------|
| BepiPred3 CPU 长序列慢 | >500 aa 序列推理可能需要数分钟 | 后续评估 GPU |
| PepMLM 当前 CPU 模式 | REAL_MODEL 在 CPU 上生成速度受限 | 后续评估 GPU |
| 尚未接结构预测 | 未集成 AlphaFold / FoldX / ColabFold | P6 审计 |
| 尚未接分子对接 | 未提供 docking / pDockQ / ΔG | P6+ |
| 尚未接湿实验验证 | 无 MIC / MBC / hemolysis / toxicity 实验数据 | P8 |
| GitHub push 网络影响 | 当前 HTTPS 推送可能因网络失败 | 本地开发优先 |
