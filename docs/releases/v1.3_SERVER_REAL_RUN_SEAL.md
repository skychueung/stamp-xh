## Deployment Method

**Native Python + nginx** (not Docker Compose).

### Why not Docker?

Server Docker daemon configured with HTTP/HTTPS proxy `192.168.28.247:10808`, which is unreachable. Docker Hub image pulls timeout:
```
proxyconnect tcp: dial tcp 192.168.28.247:10808: i/o timeout
```

### Fallback deployment
- **Backend:** `cd ~/stamp/backend && uvicorn app.main:app --host 0.0.0.0 --port 8001`
- **Frontend:** `nginx:latest` container serving `dist/` with reverse proxy `/api` → `localhost:8001`
