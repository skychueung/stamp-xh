## 1. Hotfix Reason

During v1.0-demo end-to-end verification, XLSX and PDF export requests for both **Candidate Report** and **Wetlab Validation Report** returned **404/422**.

Root cause:
- Router `format` enum only accepted `json`, `markdown`, `csv`.
- Service layer lacked `render_*_xlsx()` and `render_*_pdf()` functions.
- No API route consumed binary export renderers.

This was a known v1.0 limitation, not a data corruption bug.
