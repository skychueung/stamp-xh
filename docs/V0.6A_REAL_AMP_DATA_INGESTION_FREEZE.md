## 7. Git Commit Recommendation

### 7.1 .gitignore 建议

`data/raw/` 包含：
- `AMP结构预测1-100.zip` (~17.5 MB)
- `AMP到货批次整理_V1_20250324 更正 .xlsx`
- `化妆品防腐AMP筛选汇总_20251213-1.xlsx`
- 解压后的 `AMP结构预测1-100/` 目录（~500 CIF + ~1000 JSON）

**建议**:
- **A. 仅本地 Git 快照**: 可以提交 raw 数据，但仓库体积会显著增大（~50+ MB）。
- **B. 后续推送到 GitHub**: **强烈建议**将 `data/raw/` 和 `data/processed/` 加入 `.gitignore`，避免上传原始实验数据和大文件。

> 已更新 `.gitignore`，新增 `data/raw/` 和 `data/processed/` 排除规则。raw 数据保留在本地文件系统，不被版本控制追踪。
