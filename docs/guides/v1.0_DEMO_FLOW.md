# STAMP v1.0 Demo Flow

**Stage:** v1.0-P3  
**Audience:** Workshop participants  
**Time:** 15 minutes

---

## Step 1: Launch (2 min)

```powershell
# Terminal 1 — Backend
cd backend
uvicorn main:app --reload

# Terminal 2 — Frontend
npm run dev
```

Open http://localhost:5173

## Step 2: Create Project (2 min)

1. Click "New Project"
2. Name: `Boar TLR2 Demo`
3. Species: `Sus scrofa`
4. Save

## Step 3: Input Target Protein (3 min)

1. Navigate to "Target Protein"
2. Paste demo TLR2 sequence
3. Click "Analyze"
4. Review biophysical summary

## Step 4: Epitope Screening (3 min)

1. Navigate to "Epitope Screening"
2. Select TLR2 target
3. Run heuristic scan
4. Select window `45-58` (high surface exposure)

## Step 5: Peptide Generation (3 min)

1. Navigate to "Peptide Generation"
2. Click "Generate Complementary Peptides"
3. Review candidate table
4. **Observe the MM-GBSA Readiness Card:**
   - Orange "PILOT_ONLY" banner
   - `official ΔG: Not available`
   - Warnings about frame count and trajectory length

## Step 6: Assemble & Review (2 min)

1. Click "Assemble" on top candidate
2. Review full STAMP hybrid sequence
3. Navigate to "Final Ranking"
4. Export report (XLSX/PDF)

---

## Teaching Points

| Point | Where |
|---|---|
| In-silico ≠ experimental | Every page footer |
| Pilot MM-GBSA ≠ production affinity | Peptide Generation → Readiness Card |
| Experimental validation required | Final Ranking → export footer |
| Code enforces boundaries | Backend tests + guard + UI banners |
