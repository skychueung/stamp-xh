# STAMP v0.11 阶段性成果汇报

## 一句话总结

STAMP v0.11 已完成从**计算候选肽产生**到**实验验证数据管理**、**候选优先级决策**和**湿实验验证报告导出**的闭环，为 wet-lab 团队提供了完整的实验数据录入、管理和报告工具。

---

## 已完成核心能力（P1-P5）

| # | 能力 | 说明 |
|---|------|------|
| 1 | **实验验证数据模型** | 支持 validation run、experimental measurement、quality flag 等核心实体 |
| 2 | **MIC/MBC/溶血/毒性 measurement 录入** | 单候选详情页可直接录入多种实验指标 |

| 4 | **项目级 Dashboard** | 可视化展示项目覆盖率、验证状态分布、测量统计 |

| 7 | **wet-lab validation report 导出** | 支持 JSON / Markdown / CSV 三种格式导出完整验证报告 |

## 与 v0.10 的关系

- **v0.10**：解决"计算候选肽产生"问题（BepiPred3 表位筛选、PepMLM 序列生成、ColabFold 结构预测、pDockQ/FoldX 质量评估、composite_score 排序）。
- **v0.11**：解决"实验验证管理与候选决策"问题（实验数据录入、Dashboard 监控、优先级决策、报告导出）。

**关系**：v0.10 输出高置信度计算候选肽 → v0.11 管理这些候选肽的湿实验验证流程。

6. **Report 导出**：导出 JSON / Markdown / CSV 格式的 wet-lab validation report。

## 科学边界（关键声明）

> **实验数据必须来自真实录入，不由 AI 自动生成。**

- 系统不会预测 MIC、MBC、hemolysis 等实验值。
- 计算指标（pLDDT、pDockQ、FoldX）与实验测量在 UI 和报告中严格分离。
- SHORTLISTED 不等于 EXPERIMENTALLY_VALIDATED，人工决策仅为决策支持。
- 无实验数据时，报告明确标注"No wet-lab measurements recorded"，不显示任何默认值。
