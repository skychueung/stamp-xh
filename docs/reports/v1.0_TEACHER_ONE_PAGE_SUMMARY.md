## What is STAMP?

STAMP (Synthetic anti-infective Assisted by Machine-learning Peptide design) is a computational platform for designing targeted antimicrobial peptides. It combines:

1. **Epitope Screening** — Identify surface-exposed regions on target proteins.
2. **Targeting Peptide Generation** — Design complementary peptides that bind the epitope.
3. **STAMP Assembly** — Fuse targeting peptide + linker + killing domain.
4. **Structure Validation** — Predict 3D structure and interface quality.
5. **MM-GBSA Readiness** — Parse binding free energy estimates with strict scientific boundaries.
6. **Experimental Validation** — Record wet-lab measurements (MIC, MBC, hemolysis).
7. **Candidate Prioritization** — Rank candidates based on computational + experimental data.

## Scientific Boundaries (Non-Negotiable)

- **Computational scores are NOT experimental validation.**
- **Pilot MM-GBSA is NOT production binding affinity.**
- **All candidates default to `NOT_EXPERIMENTALLY_VALIDATED`.**
- **No fabricated MIC, MBC, hemolysis, or toxicity data.**
