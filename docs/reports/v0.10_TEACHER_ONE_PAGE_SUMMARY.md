# STAMP v0.10 阶段性成果汇报

## 一句话总结

STAMP v0.10 已完成从**真实表位预测**、**靶向肽生成**、**结构预测**、**界面质量评估**、**FoldX 能量质量评估**到**候选报告导出**的完整计算闭环。

## 已完成的核心能力

| # | 能力 | 说明 |
|---|------|------|
| 1 | BepiPred3 表位预测 | 真实 sidecar 服务，预测靶蛋白 B 细胞表位 |
| 2 | PepMLM-650M 靶向肽生成 | 真实模型 sidecar，基于表位生成长度可控的靶向肽 |
| 3 | LocalColabFold 结构预测 | 本地 ColabFold 1.6.1，预测靶蛋白-肽复合物三维结构 |
| 4 | pDockQ 界面质量评估 | 基于复合物结构计算界面质量置信度 |
| 5 | FoldX energy_quality | 基于 FoldX 5.1 计算蛋白-肽相互作用能 |
| 6 | Job System 后台任务 | 异步任务队列，支持取消、重试、错误恢复 |
| 7 | 数据库持久化 | 表位候选、靶向肽候选、结构指标、界面质量、能量质量全落库 |
| 8 | 前端综合展示 | EpitopeScreeningPage → ProjectResultsPage → FinalRankingPage 完整链路 |
| 9 | 候选报告导出 | 支持 JSON / Markdown / CSV 三种格式，含科学边界声明 |

## 可展示成果

- **表位候选** — BepiPred3 预测的 B 细胞表位及得分
- **靶向肽候选** — PepMLM-650M 生成的靶向肽序列
- **结构预测指标** — mean pLDDT、pTM（ColabFold 输出）
- **界面质量** — pDockQ 得分
- **能量质量** — FoldX interaction energy
- **导出报告** — JSON / Markdown / CSV 格式候选报告，含完整科学边界声明

## 科学边界 ⚠️

> **当前所有输出均为计算预测和模型生成结果，尚未进行湿实验验证。**

- 未声明抗菌活性已验证
- 未声明 MIC / MBC
- 未声明毒性 / 溶血已测试
- 未声明结合亲和力已测量
- docking_score 未计算
- MM-GBSA ΔG 未计算
- FoldX interaction_energy 仅为计算力场估计，不等同于 docking_score 或 MM-GBSA ΔG
