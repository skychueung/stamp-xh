## What v0.13 Delivers

v0.13 introduces the **MMPBSA parsing and scientific boundary enforcement pipeline**:

1. **Parser (`mmpbsa_result_parser.py`)**
   - Reads `FINAL_RESULTS_MMPBSA.dat` files
   - Extracts energy components, frames, convergence status
   - Auto-detects pilot vs. production from file path
   - `official_mm_gbsa_delta_g` is **always null** for pilot/smoke data

2. **Persistence Guard (`mmgbsa_persistence_guard.py`)**
   - Blocks pilot/smoke results from being written as production MM-GBSA
   - Enforces production criteria: ≥10 ns trajectory, ≥200 frames, convergence evidence
   - Returns structured `{allowed, reason, violations}` dict

3. **Frontend Readiness Card (`MmgbsaReadinessCard.tsx`)**
   - Displays pilot vs. production status with color-coded banner
   - Shows `official_mm_gbsa_delta_g` as "Not available" for pilot data
   - Lists warnings (insufficient frames, short trajectory, etc.)
   - Scientific boundary footer on every card
