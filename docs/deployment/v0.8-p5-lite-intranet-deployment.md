## 部署方式

1. **本地打包**（Windows）:
   ```powershell
   tar -czf stamp-v0.8-e2e-deploy.tar.gz \
     --exclude=node_modules --exclude=.git --exclude=dist \
     --exclude='*venv*' --exclude='__pycache__' .
   ```

2. **上传到服务器**（SCP）:
   ```powershell
   scp -i ~/.ssh/kimi_bridge_ed25519 \
     stamp-v0.8-e2e-deploy.tar.gz \
     xh@192.168.31.218:/home/xh/kxc/靶向肽/
   ```

3. **服务器解压**:
   ```bash
   tar -xzf stamp-v0.8-e2e-deploy.tar.gz -C stamp-platform-v0.8-e2e
   ```
