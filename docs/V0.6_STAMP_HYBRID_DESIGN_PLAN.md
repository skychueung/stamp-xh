## 4. 为什么当前只做 AMP monomer，不做 complex validation

| 限制 | 说明 |
|:---|:---|
| 无 target-LBP14 复合物结构 | 靶向域序列已知但无实验结构，未与 LPS 做 docking |
| 无 linker 构象数据 | RKRR/EAAAK/G4S 需实验或 MD 模拟 |
| 无 killing domain 确认 | L7 序列来自文献，P4/P15 为实验候选 |
| 无杂合肽全长序列实验验证 | R7_P4 = LBP14 + linker + P4，仅序列组装，无实验数据 |
| **无复合物实验验证** | 当前为设计阶段，无 binding affinity / docking score / ipTM / pDockQ / interface ΔG |

**结论**: 当前阶段只能展示 AMP 单体结构。杂合肽 complex 的所有界面指标（LPS docking score、ipTM、pDockQ、interface ΔG）均为 null，需后续设计完成后再预测。
